# Wisdom

Public, privacy-reviewed reading tools and source-backed knowledge surfaces.

**Live site:** https://jerryshi042003.github.io/wisdom/

This repository is the deployable public release, not a mirror of the private
personal workspace. It intentionally excludes personal calibration notes,
credentials, raw account exports, private health history, and the separately
maintained Chess, Health, Taste, Tennis CV, and David Choe projects.

The site is static HTML, CSS, JavaScript, and reviewed data. It needs no server,
database, account, or paid runtime, so GitHub Pages can keep serving the last
successful release even when no development is happening.
